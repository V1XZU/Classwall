Short Answers

1. What is the difference between a cookie and a session?

A cookie is data saved in the user's browser and can last for days. A session is data kept on the server for one visit and ends when the browser closes.

2. Where is each one stored?
   
A cookie is stored in the browser. A session is stored on the server, and the browser only keeps the session ID (PHPSESSID).

3. Why do we use prepared statements?

They keep user input separate from the SQL code, which prevents SQL injection.
